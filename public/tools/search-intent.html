Search intent guide

What is search intent?

Search intent is the purpose behind a user's search query. Understanding intent helps you create content that matches what people are actually looking for when they use a search engine.

Types of search intent

Informational intent

The user wants to learn something, answer a question, or understand a topic.

Commercial intent

The user is researching products, services, or solutions before making a decision.

Navigational intent

The user is looking for a particular website, page, brand, or destination.

Transactional intent

The user is ready to take an action such as purchasing, signing up, downloading, or requesting a service.
