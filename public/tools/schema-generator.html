Structured data guide

What Is Schema Markup?

Schema markup is structured data that describes the content of a webpage using a defined vocabulary such as Schema.org. It can help supported systems interpret entities and page details, including information about organizations, articles, products, services and events.

Structured data should accurately reflect information visible on the page. Do not add properties, reviews, prices, business details or other facts that cannot be substantiated by the actual content.

What Is JSON-LD?

JSON-LD is a way to express linked data using JSON. It is commonly added to a webpage in a script element with the type application/ld+json. Keeping the data separate from visible HTML can make it easier to maintain, but the markup still needs to be accurate and valid.

Choose a Schema Type That Fits the Page

Organization and WebSite

Organization markup can describe a real organization and its verified details. WebSite markup describes a website. Use only information that belongs to the site or organization being represented.

Article

Article markup can describe editorial content, including a headline, author and publication dates when those details are accurate and available on the page.

Product and Service

Product or Service markup should represent the actual offering. Include only applicable and verifiable attributes, and follow the relevant search engine requirements if you are aiming for a supported search feature.

LocalBusiness

LocalBusiness markup may describe a real local business and its accurate contact or location details. Never invent addresses, opening hours or other business information.

FAQPage and other types

Choose types based on the actual content and current eligibility rules. Adding a schema type does not guarantee a rich result; some search features are limited to particular content or site types.

How to Validate Schema Markup

  1. Confirm that the chosen schema type matches the page.
  2. Check every property against visible, accurate page content.
  3. Validate JSON syntax and required properties for the intended feature.
  4. Test the live URL after publishing and fix reported errors.
  5. Monitor important pages in Google Search Console where applicable.

Common Structured Data Mistakes

  • Using a schema type that does not fit the page.
  • Adding information that is not visible or cannot be verified.
  • Publishing invalid JSON or incorrect property values.
  • Assuming valid markup guarantees rich results or better rankings.
  • Failing to retest markup after page content changes.

Frequently asked questions

Schema Markup Generator FAQ

What is schema markup?

Schema markup is structured data added to a webpage to describe its content in a format understood by supported search engines and other systems.

What is JSON-LD?

JSON-LD is a format for expressing linked data using JSON. It is commonly used to add Schema.org structured data to webpages.

Does schema markup guarantee rich results or higher rankings?

No. Valid structured data does not guarantee rich results or higher rankings. Eligibility depends on search engine guidelines, supported features, page content and other factors.

How should I validate generated schema?

Check that the structured data accurately describes visible page content, confirm that the JSON is valid, and use relevant structured data testing tools before publishing.
